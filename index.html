Application Features

Vacation Planning

Create, edit, delete, and organize vacations with dates and accommodations.

Excursion Management

Manage activities associated with each vacation and schedule reminders.

Vacation Search

Quickly locate saved vacations by title or accommodation.

Photo Gallery

Add, view, and remove vacation photo references using Android's Photo Picker.

Vacation Reports

Generate a vacation summary report containing saved vacation information.

Local Data Storage

Vacation records are managed locally using Room and SQLite.

Installation Instructions

  1. Open this website on an Android device.
  2. Select Download for Android.
  3. Open the downloaded APK file.
  4. If prompted, allow installation from the source used to download the APK.
  5. Complete installation and launch Vacation Scheduler.

This is an Android application. The APK does not run directly in a web browser. Installation may be restricted by device policies.
